# FoxStoria — без локальных серверов

Python 3.14 на Mac не ставит FastAPI. Это нормально: сайт живёт как HTML.

## Что делать

1. Открыть `web/index.html` в браузере — или запушить в GitHub.
2. На GitHub: Settings → Pages → Source = GitHub Actions.
3. Сайт появится на `https://<логин>.github.io/foxstoria/`.

## Когда понадобится бэкенд

Аккаунты, оплаты, сохранение историй, каталог из базы — тогда Python 3.12 или облако. Статические страницы из `web/` остаются витриной.
